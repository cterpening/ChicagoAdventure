# Kylie & G Dog: Chicago Adventure

Play it online: **https://cterpening.github.io/ChicagoAdventure/**

Kylie and Gwen “G Dog” take a pixel-art, choose-your-own-adventure trip across Chicago. Start in Kylie’s third-floor apartment, explore the CTA-style overworld, and visit every stop in any order. Every new adventure rerolls the city’s five rotating destinations; eligible picks change with the current season.

## How to play

- Move with **WASD** or the **arrow keys**.
- On a phone or tablet, use the on-screen directional pad.
- On Xbox or another standard controller, use the left stick/D-pad to move, `A` to start or continue, and `Y` to restart.
- Leave the apartment, walk to any L stop on the overworld, and collect the adventure stamp in each location.
- Press `R` or choose Play Again to begin a new run with a newly selected seasonal lineup.
- Find extra G Dog treats hidden around the city map.

## Stops

Permanent anchors are Home, Andersonville, Wrigleyville, Loyola, Trader Joe’s, downtown, O’Hare, and Midway. Five rotating slots are picked for each run from year-round venues and season-appropriate Chicago activities. For example, summer can include Lollapalooza, North Avenue Beach, and Navy Pier fireworks; winter can include Christkindlmarket and Millennium Park ice skating.

## Run locally

Open `index.html` in a modern browser. A local web server is recommended if the browser restricts locally loaded images.
